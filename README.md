# 养老机构膳食过敏与送餐核对平台

管理住户饮食档案、过敏项、菜单营养审核、厨房批次、餐盒标签、送餐路线、
拒餐与替换记录的本地演示平台。**纯 Python 标准库实现**（SQLite + http.server +
自带二维码编码器），无需安装任何第三方依赖、无需联网。

> 所有住户姓名与健康信息均为虚构的匿名演示数据（住户·青松、A001 等）。

## 一条命令启动

```bash
./run.sh
```

该命令会：
1. 重建 SQLite 数据库，生成菜单、批次配餐、餐盒标签、送餐路线、
   错餐/漏餐/拒餐/温度不合格/家属调整等异常处置样例；
2. 启动本地服务。打开 <http://localhost:8026> 即可使用。

- 保留数据启动：`./run.sh --keep`
- 自定义端口：`PORT=8090 ./run.sh`
- 运行测试：`./test.sh`（65 个用例，纯 unittest）

演示登录（任意员工 + 四位数口令）：

## 六个页面

1. **住户饮食卡** `/residents` — 忌口、过敏等级、咀嚼要求、生效日期；
   饮食限制置顶，严重过敏使用固定位置的高对比提示；含腕带二维码。
2. **菜单审核** `/menus` — 菜单发布前必须营养审核；菜品未审核不能入菜单；
   页面给出过敏原与受影响住户核查表；含菜品审核入口。
3. **厨房批次** `/kitchen` — 只能按已发布菜单生成批次，按档案自动安全配餐；
   餐盒标签大字 + 图标 + 二维码，整批打印；测温低于 60℃ 自动登记事件。
4. **送餐路线** `/routes` — 一屏完成核对：**扫住户腕带 → 扫餐盒标签 → 自动交付**；
   支持路线交接码、拒餐登记、异常演练（错扫/旧标签/重复扫描）。
5. **异常餐盒** `/exceptions` — 错餐、漏餐、拒餐、温度不合格、家属调整分类记录；
   错餐盒立即隔离，事件处置闭环。
6. **家属确认** `/family` — 家属来电的暂停/换餐先电话复核确认再执行。

## 核心业务规则

- **过敏拦截**：严重过敏（severe）、慎食（warning）、忌口、咀嚼质地
  （普通→软食→碎末→匀浆，菜品必须不低于住户所需细软度）、特殊餐（低盐/糖尿病）
  任一不符即拦截；配餐、入菜单、替换餐三处共用同一规则引擎。
- **菜单审核**：含未审核菜品不能提交/发布；已发布菜单不可增改菜品。
- **替换餐**：只能选已审核菜品并重新过过敏拦截；**另发唯一新标签，旧标签立即作废，
  旧标签扫描会被拒绝**。
- **餐盒标签**：`日期-餐次-序号` 全局唯一；作废旧标签带"作废 DO NOT USE"水印。
- **扫码交付**：必须先住户后餐盒；重复扫描留痕但不改变状态；
  住户码不符 → 暂停交付并记异常；餐盒错配 → **错餐盒立即隔离**；
  作废/隔离标签禁止交付。
- **路线交接**：扫路线交接二维码后才可交接给另一名送餐员。
- **档案双人确认**：护理员发起后档案进入"待第二人确认"，**本人不能确认**，
  字段白名单限制（不能改 id、姓名等）。
- **已送餐记录只允许追加说明**，原始结果不可修改。
- **家属调整**：暂停供餐作废对应餐盒；换餐强制走替换餐全部规则。
- **送餐提醒**：进程内后台线程按 `reminders.fire_at` 触发，页面右下角弹出提醒。

## 本地二维码适配器

`app/qradapter.py` 为纯标准库 QR 编码器（Byte 模式、纠错等级 M、版本 1–10、
八种掩码择优、Reed-Solomon 校验），输出 SVG。`LocalScanner` 定义扫描抽象：
真实扫码枪/摄像头把解码文本传入即可（`RES:住户码` / `MEAL:标签号` / `ROUTE:路线号`），
演示页面上的"模拟扫描"按钮等价于一次扫码。

## 目录结构

```

  qradapter.py   纯标准库二维码编码 + 本地扫描适配器
  db.py          SQLite 连接、建表、审计
  seed.py        匿名演示数据（一条命令生成样例）
  services.py    领域规则：过敏拦截、审核、批次标签、替换、路线扫描、双人确认…
  webapp.py      六个页面 + 进程内提醒线程（http.server）
tests/           65 个 unittest：过敏拦截 / 标签唯一 / 路线交接 / 重复扫描 / 字段权限
run.sh           单条启动命令
test.sh          运行测试
data/mealcare.db SQLite 数据库（运行后生成）
```
